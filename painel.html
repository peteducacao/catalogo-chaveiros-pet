ACESSO AO PAINEL

Entrar com GitHub

Use um token de acesso do GitHub autorizado para este repositório.

O token fica somente nesta aba. A entrada verifica seu token e carrega os chaveiros. Para salvar alterações, o token precisa da permissão Contents: Read and write.

Como gerar meu token?

No GitHub, selecione Resource owner: peteducacao, depois Only select repositories → catalogo-chaveiros-pet e em Repository permissions → Contents: Read and write. O GitHub precisa autorizar a gravação. Gere um novo token se o atual estiver sem essa permissão. Não compartilhe o token.
