Manual do catálogo PET Educação

Tutorial completo para quem administra ou assumir o site futuramente

Este catálogo tem três páginas públicas (Início, Chaveiros e Contato) e um painel protegido para quem administra. Os dados são armazenados no GitHub e aparecem no site após a publicação do GitHub Pages. Use as etapas abaixo como referência.

1. Primeiros passos: acesso, senha e segurança
  1. Na página do Painel administrativo, entre com um token de acesso pessoal do GitHub da conta autorizada para o repositório peteducacao/catalogo-chaveiros-pet.
  2. Prefira um fine-grained personal access token com acesso somente a esse repositório e permissão Contents: Read and write. Não conceda permissões adicionais sem necessidade.
  3. Depois de entrar, o indicador Conectado aparecerá no canto superior. A notificação de acesso desaparece automaticamente.
  4. Clique em Sair quando terminar. A credencial fica apenas nesta aba durante a sessão; não compartilhe o token, não o coloque em fotografias ou mensagens e não use computadores públicos.
  5. Se a pessoa responsável mudar, revogue o token antigo no GitHub e gere uma credencial nova com acesso mínimo. Nunca entregue a credencial por WhatsApp, texto público ou nos arquivos do site.

Importante: o painel utiliza o GitHub como autorização. Quem possui um token de escrita no repositório pode alterar arquivos diretamente no GitHub. A segurança não depende apenas das verificações feitas pelo navegador.

2. Conheça as páginas do site

Início: mostra apenas o título Catálogo de Chaveiros, o texto de apresentação e os botões Ver chaveiros e Conheça o PET (Instagram). O conteúdo fica centralizado sobre um fundo claro com curvas discretas.

Chaveiros: mostra os modelos cadastrados, valores quando preenchidos, cores quando habilitadas e status de disponibilidade. Toque numa foto para ampliá-la. São exibidos até seis chaveiros por página: quando houver mais de seis, use os números e as setas abaixo dos produtos para ver os próximos. A busca pública aparece quando existem ao menos quatro chaveiros ou algum modelo com variações. Ela pesquisa todos os modelos cadastrados, por nome, descrição e cores, inclusive as combinações de cada variação, mesmo nas páginas seguintes ou sem estoque. Por exemplo, buscar preto encontra chaveiros que oferecem essa cor. Por exemplo: se houver 12 modelos de Pedagogia, aparecerão duas páginas com seis resultados cada. Ao atualizar o navegador (F5), o catálogo mantém a página e o filtro selecionados. Ao iniciar uma nova pesquisa ou trocar de filtro, a paginação volta à página 1. Sem pesquisa, os filtros Disponíveis e Sem estoque permanecem separados.

Contato: apresenta as redes sociais configuradas e, se habilitado, o link do site institucional. Os pedidos e dúvidas são direcionados ao Instagram, não a um carrinho de compras.

Painel: tem três áreas: Chaveiros, Página inicial e Contatos e links. Cada mudança só fica pública depois de ser salva e publicada.

3. Como cadastrar um novo chaveiro
  1. Abra a aba Chaveiros e clique em + Novo chaveiro.
  2. Preencha o nome do chaveiro (obrigatório). A descrição é opcional: se não houver texto, o catálogo não mostrará uma caixa ou espaço para descrição.
  3. Selecione a imagem: um arquivo do computador/celular ou um link direto HTTPS de imagem PNG, JPEG ou WebP. Se não houver imagem, o site mostra uma indicação padrão.
  4. Em Tipo de variação, escolha entre Sem variações, Uma cor variável e Combinações de duas cores. Cada variação pode ter sua própria fotografia e estoque. Veja as seções 3A e 3B deste manual para o passo a passo de cores e variações.
  5. Preencha a quantidade em estoque, informe o preço se quiser exibi-lo e marque Disponível conforme a situação.
  6. No campo O que deve aparecer na legenda da imagem?, escreva a legenda que deseja mostrar junto à fotografia, por exemplo, Imagem ilustrativa. Esse texto é opcional; deixe vazio para ocultar a legenda. Não existe mais um controle separado para ativá-la.
  7. Clique em Salvar chaveiro e aguarde a confirmação do GitHub. Não feche a página enquanto estiver salvando.

O preço é opcional. Se estiver vazio, não aparece ao público. Para um item ser considerado disponível, é necessário que a opção Disponível esteja ativa e que o estoque seja maior que zero.

3A. Gerenciar cores: adicionar, editar e excluir opções
  1. Abra a aba Chaveiros e clique em Gerenciar cores, ao lado de + Novo chaveiro. Essa opção também está disponível dentro do seletor de cores do cadastro.
  2. Para adicionar uma cor, digite um nome (por exemplo, Rosa-claro), escolha a tonalidade no quadrinho colorido e clique em Adicionar cor. Aguarde o salvamento no GitHub.
  3. Para editar, localize a cor na lista, clique em Editar, modifique o nome ou a tonalidade e pressione Salvar alterações.
  4. Para excluir, clique em Excluir na cor desejada e confirme. Ela deixará de aparecer como opção para novas variações, mas não será retirada dos chaveiros já salvos.
  5. As cores de cada produto são escolhidas diretamente em Variações do chaveiro, com fotografia e estoque próprios quando necessário. O seletor antigo de cores foi removido para evitar cadastros duplicados.

Atenção: alterar ou excluir uma cor do gerenciador não modifica automaticamente as cores já associadas aos produtos. Para alterar as cores de um chaveiro, abra Editar e use Variações do chaveiro. O gerenciador admite até 80 opções.

3B. Variações: fotos individuais, combinações e estoque
  1. Na aba Chaveiros, abra + Novo chaveiro ou Editar em um modelo existente. Primeiro, escolha a imagem principal; ela é a fotografia exibida antes de alguém selecionar uma variação.
  2. Em Variações do chaveiro → Tipo de variação, escolha: Sem variações (modelo fixo), Uma cor variável ou Combinações de duas cores.
  3. Clique em + Adicionar variação. Se escolheu uma cor variável, selecione uma cor; para combinações, selecione duas. Cada combinação deve ser diferente das demais. Você pode cadastrar até 24 variações por chaveiro.
  4. Na própria linha dessa variação, em Foto desta variação (opcional), selecione uma fotografia no celular ou computador. O painel prepara um arquivo WebP de 960 × 960 pixels. A foto fica vinculada àquela opção e é enviada ao GitHub ao clicar em Salvar chaveiro.
  5. Repita o procedimento para cada opção. Para trocar a foto depois, abra novamente Editar, encontre a variação e selecione outro arquivo. Para usar a foto principal, clique em Remover foto na variação e salve o chaveiro.
  6. O campo Estoque (opcional) funciona assim: em branco utiliza o estoque geral do produto; 0 marca apenas aquela variação como indisponível; 1 ou mais permite selecionar aquela variação quando o produto estiver disponível.
  7. Finalize em Salvar chaveiro e aguarde a confirmação. No catálogo, os visitantes veem o botão Ver opções de cores, que mantém a lista recolhida para não alongar o cartão no celular. Ao tocar nele, aparecem todas as variações cadastradas em uma área rolável. Tocando em uma opção, a fotografia principal é substituída no mesmo lugar, sem acrescentar outra imagem abaixo; a opção esgotada é identificada ali como indisponível. O botão Ocultar opções de cores recolhe a lista novamente, mantendo a escolha feita.
  8. Copiar detalhes para encomenda: clique em Copiar detalhes da encomenda no cartão e abra o Instagram para colar as informações na conversa. O texto inclui nome, combinação escolhida e preço (se informado). Quando há variações, selecione primeiro uma opção disponível; o botão fica desativado para opções esgotadas. Esse recurso não envia mensagens automaticamente, nem acessa sua conta.

Importante: a aba Sem estoque continua destinada apenas aos chaveiros indisponíveis como um todo. Uma variação com estoque zero não desloca o chaveiro para essa aba. Se o produto inteiro estiver com estoque geral zero ou marcado como indisponível, ele irá para Sem estoque, independentemente das variações.

Se não houver fotografia individual, o site mantém a imagem principal e informa que a aparência da variação escolhida pode ser diferente. A foto própria é opcional, mas recomendamos cadastrar uma para cada combinação quando você tiver imagens reais. No celular, a fotografia do catálogo se ajusta à altura da tela e permanece inteira, sem ser cortada; toque nela para ampliar.

4. Fotografias: segurança, rotação e enquadramento
  1. Para melhor qualidade, prepare uma foto de 960 × 960 pixels, de preferência quadrada. Você pode enviar outra proporção e enquadrar no próprio painel; o arquivo final é convertido para WebP quadrado de 960 × 960 px. São aceitos PNG, JPEG ou WebP, até 15 MB e 60 megapixels. O painel recusa SVG e arquivos incompatíveis.
  2. Após selecionar, use a janela de enquadramento: Mostrar inteira evita cortes; Preencher quadro pode cortar bordas. Arraste para centralizar, ajuste o tamanho e use os botões de girar 90° quando necessário.
  3. Clique em Usar este enquadramento; confira a prévia e só então salve o chaveiro.
  4. O arquivo é conferido e a fotografia é convertida para um novo WebP pelo navegador. Isso evita publicar os bytes e metadados originais e reduz o risco de conteúdo escondido no arquivo.
  5. Na opção Usar link, informe somente um endereço HTTPS direto terminado em .png, .jpg, .jpeg ou .webp. Links de páginas, SVG e arquivos HTML não são permitidos.

Atenção: não envie arquivos de origem duvidosa. As verificações no navegador reduzem riscos, mas não substituem a segurança do GitHub e do próprio dispositivo. URLs de imagens externas pertencem a outros servidores e podem deixar de funcionar.

5. Editar, excluir e ordenar chaveiros

Editar: na aba Chaveiros, localize o modelo e toque na foto, no nome ou no botão Editar. Os três abrem o mesmo formulário. No celular, basta tocar uma vez; no computador, também é possível usar Tab e Enter nos atalhos. Faça as alterações e pressione Salvar chaveiro.

Resumo das cores: na lista Meus chaveiros, modelos com cores comuns mostram as cores cadastradas; modelos com variações mostram apenas Variações de cores, sem listar as combinações ou quantidades, para deixar o cartão mais limpo. Para consultar ou editar todas as opções, toque na fotografia, no nome ou em Editar.

Disponibilidade: use o controle do cartão ou ajuste o campo no editor. Estoque igual a zero deixa o modelo indisponível mesmo com a opção habilitada.

Ordenação: chaveiros recém-cadastrados entram automaticamente na última posição, sem deslocar os anteriores para o começo. Para reorganizar, deixe a busca do painel vazia e use as setas Subir/Descer ou o seletor de posição. Essas mudanças são gravadas automaticamente no GitHub; aguarde a confirmação.

Excluir: clique em Excluir, confira o modelo e confirme somente se tiver certeza. A exclusão remove o registro do catálogo; o histórico do GitHub poderá ajudar a recuperar alterações anteriores, mas não há botão de desfazer no painel.

Busca: use o campo de busca para localizar um modelo quando existirem muitos cadastrados.

6. Selo Novo e gerenciamento de coleções

Como ativar e escolher o prazo do selo Novo: abra a aba Chaveiros e clique em Editar no modelo. Marque Destacar como Novo e, imediatamente abaixo, escolha a duração: 1, 3, 7, 15 ou 30 dias, ou Até eu desmarcar. Clique em Salvar chaveiro. Cada modelo pode ter seu próprio prazo, sem depender da página inicial.

Vencimento automático: o período começa no momento em que o produto é salvo. Depois do prazo, o selo deixa de aparecer no catálogo e a opção Destacar como Novo aparece desmarcada quando o editor é aberto. Não é necessário alterar o cadastro para que o selo desapareça. Se quiser um novo período, marque novamente e salve. Desmarcar manualmente e salvar cancela o selo imediatamente.

Gerenciar coleções: na aba Chaveiros, clique em Gerenciar coleções ou use o mesmo botão ao editar um produto. Digite o nome (por exemplo, Religião ou HarryPotter) e clique em Adicionar coleção. Os nomes cadastrados aparecem no seletor Coleção (opcional) do editor; escolha a coleção e salve o chaveiro. Para excluir uma coleção da lista, ela não pode estar associada a nenhum produto: primeiro atribua outra coleção ou escolha Sem coleção nos produtos relacionados.

Modelos relacionados: ao ampliar uma imagem no catálogo, até três modelos da mesma coleção serão sugeridos, preservando fotografias, variações, estoque e paginação. Os nomes com o padrão HarryPotter - Tipo 1, HarryPotter - Tipo 2 etc. também são identificados automaticamente como uma coleção quando não há associação explícita.

7. Editar o texto da página inicial
  1. Abra a aba Página inicial do painel.
  2. Edite o campo Texto de apresentação na página inicial conforme desejar.
  3. Clique em Salvar apresentação e aguarde a confirmação do GitHub.

A página inicial contém somente o título Catálogo de Chaveiros, o texto de apresentação e dois botões: Ver chaveiros abre o catálogo e Conheça o PET abre o Instagram institucional. Não há seleção ou exibição de fotos de chaveiros na página inicial.

8. Configurar redes sociais e site institucional

Na aba Contatos e links há duas áreas na mesma tela:

  1. Redes sociais: preencha o nome da rede (Instagram, YouTube etc.), perfil, URL HTTPS e descrição opcional. Clique em Adicionar rede social. Para modificar ou apagar uma rede cadastrada, use os controles Editar ou Excluir no cartão correspondente.
  2. Site institucional: altere título, endereço HTTPS e descrição. A opção Mostrar o site na página de Contato permite ocultar o link sem apagar suas informações. Clique em Salvar site institucional.

Endereço e contatos institucionais: na aba Contatos e links, abra Localização e informações de contato. Preencha campus, endereço, cidade, CEP, telefone e e-mail. Pressione Salvar informações e aguarde a confirmação. Os dados serão exibidos no rodapé e na página Contato. O botão Visualizar mapa carrega a localização quando o visitante solicitar, evitando deixar o site pesado.

Como escolher o fundo de cada rede: no formulário de Redes sociais, marque Personalizar a cor, selecione a tonalidade e confira a prévia. Clique em Adicionar rede social ou Salvar alterações. A cor pertence somente àquele perfil e também pode ser definida para redes adicionadas depois. Para voltar à cor original, desmarque a opção e salve. O texto muda automaticamente entre claro e escuro para facilitar a leitura.

Revise os links depois de salvar, principalmente quando uma conta ou site institucional for alterado. O Instagram do catálogo é o canal indicado para dúvidas e encomendas.

8. Como verificar a publicação e resolver problemas
  1. Depois de salvar, aguarde a mensagem de confirmação do GitHub. A página pública pode levar alguns minutos para refletir a mudança pelo GitHub Pages.
  2. Várias alterações seguidas: o painel agora coloca as gravações do repositório em sequência, incluindo fotos, produtos e configurações. Você pode solicitar duas ou mais mudanças; aguarde as confirmações antes de fechar a aba. Quando houver alterações de chaveiros aguardando gravação, o painel informará a fila.
  3. Conexão instável ou dois cliques seguidos: o painel lê sempre a versão mais recente do arquivo e tenta novamente em falhas de rede ou conflitos temporários. Quando aparecer Conferindo conexão com o GitHub, aguarde a confirmação, sem fechar a aba. Alterações de disponibilidade são repetidas de modo seguro, sem inverter o estoque ou a opção duas vezes. Se, mesmo após todas as tentativas, aparecer Gravação não confirmada, confira o estado do produto no GitHub antes de tentar novamente. Uma alteração não confirmada não será apresentada como estoque salvo.
  4. Abra a página inicial, o catálogo ou a página de contato para conferir o resultado.
  5. Se uma informação antiga continuar aparecendo, atualize a página ou abra o site em uma aba anônima, considerando o tempo de publicação.
  6. Em caso de erro 401/403, confira a validade do token e as permissões Contents: Read and write. Se houver conflito ao salvar, atualize o painel antes de tentar novamente.
  7. Se a foto não aparecer, confirme que o arquivo foi enviado ou que o link externo é um endereço direto de imagem. No caso de variações, confira se a imagem foi anexada à combinação correta.
  8. Revisão final no celular: verifique a foto sem cortes, a abertura de opções, o estoque de cada variação, a pesquisa por cores, a paginação, a cópia dos detalhes e os formulários do painel. Depois de salvar, confirme o resultado publicado antes de repetir a operação.

Use o histórico de publicações para verificar falhas no GitHub Pages. Se um salvamento falhar, não presuma que foi publicado: procure a confirmação.

9. Orientações para quem assumir a administração
  1. Confirme quem tem acesso administrativo ao repositório e peça ao responsável anterior a transferência de permissões por meio do GitHub, sem compartilhar tokens antigos.
  2. Leia este manual e faça primeiro uma pequena alteração de teste, aguardando a publicação.
  3. Antes de exclusões grandes, mantenha uma cópia de data/chaveiros.json e data/config.json pelo histórico do GitHub.
  4. Evite editar diretamente os arquivos HTML, CSS e JavaScript se não conhecer a estrutura do projeto. Use o painel para administrar os produtos e contatos.
  5. Se houver problemas técnicos, consulte os registros de alterações e a aba Actions do GitHub. Não divulgue tokens, senhas ou dados privados em chamados públicos.

O projeto e seus dados ficam no repositório peteducacao/catalogo-chaveiros-pet. Alterações feitas no painel são registradas como commits, permitindo rastrear o histórico.
